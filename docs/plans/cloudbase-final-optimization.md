# CloudBase 小站最后优化

不重写聊天、不加部署工具。原生 Git main 自动部署 + 自动灰度全量切流量。

1. 先补租约/生命周期回归，再改代码：移除镜像时间戳排序和本地回退标记。只有平台路由来的新 API/WS 连接能请求交接，后台续租/健康检查/旧 WS 消息不能主动驱逐。事务预留指定接管者，仍保留所有权/有效期写入 fencing。
2. 失去租约先断开 WS、排空旧队列并清空内存，再释放；保留健康端口，停止后台抢租重试，避免旧容器不断退出重启。新请求可从持久化元数据恢复。
3. 前台聊天室定时同源 HTTP 检查，走新版本路由，已有旧 WS 也能完成交接。
4. 云端首次副本设0～1；旧版无流量后平台缩容至零，不承诺即时销毁或自动删除历史镜像。启动前验证云数据库可访问，缺变量/权限失败不开放健康端口。
5. 保留 Dockerfile 测试门槛和原生Git授权/Webhook。环境变量是否继承由云端自动部署配置决定，本地不能代平台设置；首次需保存并通过一次 main 提交验收。
6. 验证单测、类型、构建、双浏览器、仅生产依赖运行、源包一致性；明确云端/Docker未验证边界。

本地验收完成：15文件112项单测、四工作区类型检查、协议检查和构建通过；12组手机浏览器检查、生产依赖运行及源包核验结果见TEST-RESULTS。限定代码审查APPROVE。无真实腾讯云/Docker验证。

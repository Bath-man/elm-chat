# 当前架构

本页描述当前 Node.js/CloudBase 版本。迁移前的 Worker/Durable Object 说明见[上游架构归档](archive/upstream/docs/architecture.md)。

## 运行与通信

- `apps/web/`：React + Vite，开发端口3000；同源 `/api` 和 WebSocket 代理到本地8080。
- `apps/server/`：Node HTTP/WebSocket 服务，生产同源提供前端静态文件、房间 API 和密文中继。
- `packages/shared/`、`packages/crypto/`：沿用的通信类型和端到端加密实现。提醒、调查等内容包装在加密文字内，不新增明文互动事件。
- 生产使用 CloudBase 文档数据库保存房间、邀请和准入身份；数据库租约只允许一个活动服务实例。无流量旧版本可缩容，发布可能短暂断线。
- 本地开发可用 `.data/rooms.json` 保存房间元数据；生产禁止退回容器临时文件。

## 本地记录与备份

- `history.ts`：IndexedDB 按房间和会话隔离，存本机明文记录、待发状态和互动载荷；服务器不持久化聊天正文或密文历史。
- 页面先加载最近约100条，向上分批读取旧记录；互动状态与待发送上下文单独读取。旧数据库首次升级需要一次索引迁移，普通打开不再读取全部普通历史。
- 加载更早消息时补偿滚动位置；用户离开底部时，新消息不会强制拉回底部。
- `history-archive.ts`：导出时读取当前会话完整历史，本地使用 PBKDF2-SHA256（210,000次）派生 AES-GCM-256 密钥；每份备份生成16字节随机盐、12字节随机 IV，保存版本与格式参数。
- `.achat` 导入在本地解密、校验并按消息 ID 合并到当前会话，保留原时间和内容。导入记录不进入待发队列，也不触发历史提醒、调查或其他状态互动。

备份加密不改变在线通信协议，也不加密 IndexedDB 本身。密码不发送给服务器；忘记密码无法解密备份。清理网站数据仍会丢失未备份的本机历史。

## 边界

两人聊天，无账号、群聊、聊天附件或云同步。身份沿用标签页会话，导入记录不恢复房间身份或未完成互动。端点设备、对方保存内容和网络元数据不在本机备份加密的保护范围内。

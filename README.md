# 极简匿名聊天

基于 [shawnbure/elm-chat](https://github.com/shawnbure/elm-chat) 的双人聊天应用，使用 React/Vite、Node.js 和 WebSocket，部署到腾讯 CloudBase 云托管。无需账号，支持端到端加密、浏览器本地记录和密码加密备份。

**房间只存在于服务进程内存中。** 重启、实例回收、缩容至零、部署或回退后，房间和邀请失效，需要重新建房。浏览器已有记录不清除，也不上传服务器。

## 快速开始

需要 Node.js 22+、npm；生成源码 ZIP 另需 Python 3。

```bash
npm ci
npm run build
npm run dev
```

打开 http://localhost:3000。前端将 `/api` 和 WebSocket 代理到本地 Node 服务的 8080 端口。运行生产构建使用 `npm start`，访问 http://localhost:8080。

无需数据库或云端凭证。可选配置见 [.env.example](.env.example)；开发命令自动读取本地 `.env`，生产启动使用终端或部署平台提供的变量。

1. 创建房间，点击“邀请”，复制链接给另一人。
2. 用另一个浏览器、独立隐私窗口或另一台设备打开链接。同一浏览器的普通标签共享身份，不适合模拟两人。
3. 输入文字发送；“+”菜单提供图片、提醒、调查及其他互动，也可导入、导出记录。
4. 提醒和调查在线收到后按顺序全屏展示。提醒确认会更新原提醒状态，调查回复显示所选答案。

真机访问需要 HTTPS，普通 `http://局域网IP` 无法提供聊天所需的 Web Crypto 安全上下文。后台或锁屏可能暂停连接，应用不提供系统推送。

## 功能与数据边界

| 内容 | 当前行为 |
| --- | --- |
| 双人准入 | 每房间最多两个身份，断线仍占席；邀请默认 10 分钟、一次有效 |
| 加密通信 | AES-GCM、ECDH、ECDSA 及成员变更密钥轮换；服务器仅实时转发加密消息 |
| 文字和图片 | PNG/JPEG/GIF/WebP 单张不超过 4 MiB；图片分块加密传输，完整接收后保存到本机 |
| 互动 | 提醒、单选调查、点赞、涂改、置顶、骰子和隐藏文字；互动内容封装在加密消息中 |
| 本地历史 | IndexedDB 按房间和会话保存；默认加载最近约 100 条，上翻加载更早记录；支持查找已加载消息 |
| 备份 | `.achat` 在浏览器内用密码加密和解密；包含完整记录与图片；导入按消息 ID 去重，仅本地显示，不发送或触发旧互动 |
| 断网恢复 | 原进程和房间仍存在时自动重连、恢复席位并尝试发送本机待发消息 |
| 房间失效 | 停止重连并提示新建房间；旧页面仍可查看、导入和导出记录，旧待发消息不会转移到新房间 |

本地 IndexedDB **存放明文记录**，`.achat` 只加密导出的文件，不加密浏览器存储。清理网站数据会丢失未备份的历史，忘记备份密码无法解密。不要在公用设备使用。

身份密钥和恢复凭证保存在当前浏览器同源的 localStorage。换浏览器、换域名或清理网站数据后无法恢复原身份。服务端没有聊天历史、离线邮箱、账号恢复或跨设备同步；不提供群聊、通用附件或音视频。

## 部署与开发

CloudBase 保留根目录 Dockerfile 和 Git `main` 自动部署。**整个生产服务只允许一个接流量实例、一个 Node 进程**；最大副本 1 不能避免跨版本交叠，发布需停旧并断开旧 WebSocket，再切到唯一新实例。最小实例 0 允许缩零并丢房；设为 1 也不保证持久化。

- [CloudBase 部署](docs/cloudbase-deploy.md)：配置、发布、回退和故障处理。
- [开发与验证](CONTRIBUTING.md)：本地检查、浏览器脚本、常见环境问题和源码打包。
- [文档索引](docs/README.md)：架构、设计、安全及验证结果。
